# Documentation and issue reports

This bundle describes the commit that built the image. Online documentation
at https://docs.projectbluefin.io/utah may describe a newer image.
Use the source map for ownership and report Utah image faults at
https://github.com/projectbluefin/utah/issues (also `BUG_REPORT_URL` in
os-release). Include the booted image version, flavor, reproduction steps,
and relevant logs after reviewing them for personal information.

Documentation repairs are checkout work. Utah owns its README and this
bundle; projectbluefin/documentation owns the website's wrapper and live
catalog. Read the checkout's docs-parity skill before changing user-facing
claims, so the website and repository remain consistent.
